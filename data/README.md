# Data / Knowledge Base

This folder contains the test data used for the Northstar Support MVP.

## Files

### orders.csv

Contains realistic sample order information used for testing
Order Status requests.

### policy.csv

Contains realistic sample information used for testing
Returns & Refunds requests.

## Purpose

The data supports testing of the two supported MVP categories:

- Order Status
- Returns & Refunds

The data is intended for testing and demonstration of the MVP.

## Data Usage

The data is provided as structured test data that can be used
by the AI and Automation components of the system.

## Data Privacy

The dataset contains fictional/test information and should not
contain real customer personal information.
